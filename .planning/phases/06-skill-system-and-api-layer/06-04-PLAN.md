1. Create `openarena_perception/api/metrics.py` with:
   - Module-level Prometheus metric singletons:
     - `PERCEPTION_FPS = Gauge("bot_perception_fps", "Perception pipeline FPS")`
     - `KILL_COUNTER = Counter("bot_kills_total", "Total kills")`
     - `DEATH_COUNTER = Counter("bot_deaths_total", "Total deaths")`
     - `LLM_LATENCY = Histogram("bot_llm_latency_seconds", "LLM strategy call latency", buckets=[0.5, 1.0, 2.0, 4.0, 8.0, 15.0])`
     - `STUCK_COUNTER = Counter("bot_stuck_total", "Times bot got stuck")`
     - `TICK_DURATION = Histogram("bot_tick_duration_seconds", "Game tick duration", buckets=[0.01, 0.02, 0.03, 0.05, 0.08, 0.1])`
   - `metrics_app = make_asgi_app()` from prometheus_client
   - CRITICAL: Use `from prometheus_client import Counter, Gauge, Histogram, make_asgi_app, CollectorRegistry` -- if tests run in same process, use a custom registry to avoid "metric already exists" errors. Create `REGISTRY = CollectorRegistry()` and pass to all metrics. Then `metrics_app = make_asgi_app(registry=REGISTRY)`.
   - Actually, for production use the default registry. For test isolation, the test should handle cleanup or use the default registry. Use default registry -- simpler, and Prometheus metrics are inherently singletons.

2. Create `openarena_perception/api/ws.py` with:
   - `_active_connections: set[WebSocket] = set()` module-level
   - `ws_router = APIRouter()` 
   - `@ws_router.websocket("/ws/state")` handler:
     - Check `len(_active_connections) >= settings.api_ws_max_connections` -> close with code 1013 (try again later)
     - Accept connection, add to _active_connections
     - Calculate interval from `1.0 / settings.api_ws_hz`
     - Loop:
       - Get bot.last_sa
       - If SA is not None: build dict manually (NOT dataclasses.asdict -- too slow per research pitfall 3), send via ws.send_json()
       - If SA is None: send `{"type": "waiting"}` heartbeat
       - await asyncio.sleep(interval)
     - On WebSocketDisconnect: remove from _active_connections
     - Wrap in try/finally to ensure cleanup

   Manual dict construction for SA (fast path, ~0.05ms vs 0.5ms for asdict):
   ```python
   {
       "tick": sa.tick, "timestamp": sa.timestamp,
       "health": sa.health, "armor": sa.armor, "ammo": sa.ammo,
       "weapon": sa.weapon, "is_alive": sa.is_alive,
       "disposition": sa.disposition, "enemies_visible": sa.enemies_visible,
       "current_area": sa.current_area, "has_path": sa.has_path,
       "is_stuck": sa.is_stuck, "under_attack": sa.under_attack,
       "pos": list(sa.pos) if sa.pos else None,
       "yaw": sa.yaw, "nav_target": sa.nav_target,
   }
   ```

3. Update `openarena_perception/api/app.py`:
   - Import ws_router from api.ws, include with app.include_router(ws_router)
   - Import metrics_app from api.metrics, mount with app.mount("/metrics", metrics_app)

4. Add tests to `tests/test_api.py`:
   - `test_websocket`: Connect to /ws/state, receive at least 1 message, verify JSON has "tick" or "type" key, disconnect
   - `test_websocket_no_sa`: With last_sa=None, verify receives {"type": "waiting"}
   - `test_metrics`: GET /metrics returns 200, body contains "bot_perception_fps", "bot_kills_total"
   - `test_metrics_content_type`: Response content-type is text/plain or similar Prometheus format

   For WebSocket tests, use httpx's WebSocket support or FastAPI's TestClient (starlette.testclient.TestClient supports WebSocket via `with client.websocket_connect("/ws/state") as ws`).
