  <action>
    Create openarena_perception/perception/sound_parser.py with three classes:

    1. **GameEvent** (frozen dataclass):
       - timestamp_game: str (e.g., "20:40")
       - timestamp_real: float (time.time() when parsed)
       - event_type: str ("Kill", "Item", "InitGame", "ClientConnect", "ClientDisconnect")
       - client_id: int (-1 for InitGame)
       - data: str (raw remainder after event prefix)
       - For Kill events, also parse: killer_id, victim_id, means_of_death (from "Kill: killer victim mod: ..." format)
       - For Item events, also parse: item_name (from "Item: client_id item_name" format)

    2. **IncrementalLogReader**:
       - __init__(self, path: str) -- stores path, offset=0, inode=0
       - read_new_lines(self) -> list[str] -- seeks to offset, reads new data, updates offset. Detects file rotation via os.stat() inode/size comparison. Returns empty list on FileNotFoundError.
       - reset(self) -- resets offset to 0

    3. **ConsoleLogParser**:
       - __init__(self, log_path: str) -- creates IncrementalLogReader internally
       - poll(self) -> list[GameEvent] -- reads new lines, parses each with regex, returns structured events
       - Use compiled regex patterns at module level:
         - _RE_KILL = re.compile(r"(\d+:\d+)\s+Kill:\s+(\d+)\s+(\d+)\s+(\d+):\s+(.+)\skilled\s+(.+)\sby\s+(MOD_\w+)")
         - _RE_ITEM = re.compile(r"(\d+:\d+)\s+Item:\s+(\d+)\s+(\S+)")
         - _RE_INITGAME = re.compile(r"(\d+:\d+)\s+InitGame:")
       - Lines that don't match any pattern are silently skipped (no log, no error)
       - reset(self) -- delegates to reader.reset(), useful on map change

    Write tests in tests/test_sound_parser.py. Use tmp_path fixture to create temporary log files for testing. Write tests FIRST (red), then implement (green).
  </action>
