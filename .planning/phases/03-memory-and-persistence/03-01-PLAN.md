<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem -> SQLite | JSON migration reads untrusted files from disk into DB |
| settings -> db_path | User-configurable path used in SQL connection string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | T (Tampering) | db_path | mitigate | Use Path.expanduser() only, no shell expansion. SQLite path is not a SQL injection vector (it's a file path, not a query parameter). |
| T-03-02 | I (Information Disclosure) | bot.db | accept | Game data only, no PII. DB file permissions default to user-only on Linux. |
| T-03-03 | D (Denial of Service) | WAL mode | mitigate | busy_timeout=5000 prevents indefinite lock contention. cache_size capped at 8MB. |
</threat_model>
