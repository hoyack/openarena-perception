1. Create `openarena_perception/memory/working.py` with a `WorkingMemory` dataclass:
   - Fields: match_id (str, default ""), map_name (str, default ""), match_start (float, default 0.0), deaths (int, default 0), kills (int, default 0)
   - `recent_events`: deque with maxlen=100 (ring buffer for recent events)
   - `last_death_position`: tuple[float, float, float] | None = None
   - `last_kill_position`: tuple[float, float, float] | None = None
   - `recently_visited_areas`: deque with maxlen=20
   - `danger_zones`: dict[int, float] (area_id -> timestamp, decays over time)
   - Method `add_event(event_type: str, data: dict[str, Any]) -> None`: appends {"type": event_type, "time": time.time(), **data} to recent_events
   - Method `get_recent_events(event_type: str | None = None, limit: int = 10) -> list[dict]`: filters recent_events by type if given, returns last N
   - Method `reset() -> None`: zeros kills/deaths, clears all deques and danger_zones
   - Method `visit_area(area_id: int) -> None`: appends to recently_visited_areas
   - Method `mark_danger(area_id: int) -> None`: sets danger_zones[area_id] = time.time()
   - Method `is_dangerous(area_id: int, decay_seconds: float = 30.0) -> bool`: returns True if area_id in danger_zones and time.time() - timestamp < decay_seconds
   - This class is NOT a frozen dataclass -- it is mutable, in-process, and never touches the DB.

2. Create `openarena_perception/memory/episodic.py` with an `EpisodicMemory` class:
   - Constructor takes `engine: Engine` (SQLAlchemy sync engine)
   - Method `record_event(match_id: str, event_type: str, map_name: str, position: tuple[float, float, float] | None = None, details: dict | None = None) -> None`: inserts into match_events table with current timestamp. Uses `with self._engine.connect() as conn:` + `conn.execute(insert(match_events).values(...))` + `conn.commit()`.
   - Method `get_deaths(map_name: str, limit: int = 50) -> list[dict]`: selects from match_events where event_type="death" and map_name matches, ordered by timestamp desc, limited. Returns list of dicts with position_x/y/z and details.
   - Method `get_match_events(match_id: str) -> list[dict]`: selects all events for a match_id, ordered by timestamp.
   - Method `get_events_by_type(event_type: str, map_name: str | None = None, limit: int = 50) -> list[dict]`: flexible query by event type, optional map filter.
   - Method `get_death_heatmap(map_name: str) -> list[tuple[float, float, float, int]]`: returns (x, y, z, count) grouped by position (rounded to nearest 100 units) for death clustering analysis.
   - All methods use SQLAlchemy Core expressions (select, insert), NOT raw SQL strings.
   - Import match_events table from `.schema`.
