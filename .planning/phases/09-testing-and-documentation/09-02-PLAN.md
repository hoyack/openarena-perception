**class TestPidMathProperties** (per TEST-06 -- PID math):
- test_pid_output_bounded: For any float error in [-1000, 1000] and any dt in [0.001, 0.1], PID output is finite (not NaN/inf). Use @given(st.floats(min_value=-1000, max_value=1000), st.floats(min_value=0.001, max_value=0.1))
- test_pid_zero_error_zero_output: When error is 0 and integral is 0, PID output is 0
- test_pid_sign_matches_error: For non-zero error with fresh PID state, output sign matches error sign (proportional term dominates)
- test_pid_integral_accumulates: After N steps with constant positive error, integral term is positive

**class TestNavigationCoordinateProperties** (per TEST-06 -- navigation coordinates):
- test_world_grid_roundtrip: For any world coordinate in map bounds, _world_to_grid then _grid_to_world produces a coordinate within one cell size of the original. Use @given(st.floats(min_value=-4000, max_value=4000), st.floats(min_value=-4000, max_value=4000))
- test_yaw_diff_bounded: For any two yaw values in [0, 360), _yaw_diff returns a value in [-180, 180]. Use @given(st.floats(min_value=0, max_value=360), st.floats(min_value=0, max_value=360))
- test_yaw_diff_antisymmetric: _yaw_diff(a, b) == -_yaw_diff(b, a) for non-boundary cases
- test_edge_penalty_non_negative: For any edge, edge_penalty returns >= 1.0

**class TestPathfindingProperties** (per TEST-06 -- pathfinding):
- test_path_starts_at_source: If _astar returns a non-empty path, first element is the start area
- test_path_ends_at_goal: If _astar returns a non-empty path, last element is the goal area
- test_path_no_duplicates: A valid path contains no duplicate consecutive areas
- test_trivial_path: _astar(area, area) returns a single-element path [area]

Use hypothesis settings(max_examples=200) for math tests to get good coverage without being slow. Use @example decorators for known edge cases (0, -180, 360, etc.).
