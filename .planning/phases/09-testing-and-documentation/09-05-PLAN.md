**docs/getting-started.md** (per DOCS-06):

**## Prerequisites**:
- Raspberry Pi 4 or 5 (4GB+ RAM recommended)
- Raspberry Pi OS Bookworm (64-bit)
- OpenArena installed and runnable
- Python 3.11+ (ships with Bookworm)
- uv package manager

**## Installation**:
Step-by-step with exact commands:
1. Clone the repository
2. Install uv: `curl -LsSf https://astral.sh/uv/install.sh | sh`
3. Install dependencies: `uv sync`
4. Verify: `uv run pytest -x -q` (all tests should pass)

**## OpenArena Setup**:
- Installing OpenArena on Pi
- Configuring named pipe: creating /tmp/openarena_pipe
- RCON setup for remote control
- Loading AAS navigation files for maps

**## Calibration**:
- Screen resolution matching (screen_w, screen_h must match game window)
- Enemy color mode selection (red/blue based on team)
- HUD region calibration for OCR
- Yaw calibration (reference the Q3 yaw formula from project memory)

**## First Run**:
- Start OpenArena
- Start the bot: `uv run python -m openarena_perception.loop` (or however the main entry point works -- check loop.py)
- Start the API: `uv run uvicorn openarena_perception.api.app:create_app --factory --host 0.0.0.0 --port 8000`
- Verify bot is playing: check API health endpoint, observe game

**## Troubleshooting**:
- Common issues: pipe not found, OCR not reading HUD, bot stuck, LLM timeout
- Each with cause and fix
