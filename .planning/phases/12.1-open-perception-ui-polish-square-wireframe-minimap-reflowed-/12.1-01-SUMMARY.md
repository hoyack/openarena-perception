# Phase 12.1 Plan 01: AAS Current-Floor Filter Summary

Pure-function AAS helper `areas_on_floor(graph, bot_z, z_tolerance=24.0)` that returns the indices of AAS areas whose vertical extent overlaps the bot's current z band, unblocking Plan 12.1-03's multi-story minimap overlay.

## What Was Built

- Added `areas_on_floor()` to `openarena_perception/navigation/aas_parser.py` as a module-level helper. Iterates `graph.areas`, skips index 0 (dummy, matching `nearest_area`), and includes an area when its `[mins[2], maxs[2]]` overlaps `[bot_z - z_tolerance, bot_z + z_tolerance]`.
- Added `tests/test_aas_parser.py` with 7 unit tests covering:
  1. Area containing bot_z is included
  2. Area far above is excluded
  3. Area far below is excluded
  4. Tolerance band lower-edge inclusivity (lower edge 20 <= 0+24)
  5. Dummy area 0 is never returned (even when its 0..0 range contains bot_z)
  6. Result is `list[int]` (sorted example `[1, 2]`)
  7. Real `maps/oa_dm1.aas` returns a non-empty proper subset (skips cleanly if file missing or parse fails)

None — plan executed exactly as written.

## Decisions Made

- Kept implementation minimal: a single module-level function, no `__all__` mutation (the module already exposes its public API implicitly).
- Real-map test asserts `1 in subset` rather than `a1.idx in subset` (plan allowed either) because `a1.idx` equals `1` by parser convention and this is clearer.
