# Phase 12.1 Plan 02: Square Wireframe + Stacked Minimap Layout Summary

Re-geometried the Open-Perception HUD from a 1400x700 three-column layout into a compact 760x720 window where a 360x360 wireframe square and a 360x360 minimap square stack on the left and the 400x720 stats panel runs full-height on the right.

## What Was Built

### Task 1 — Layout constants + square wireframe defaults

- Replaced the old `PANEL_MINIMAP_W=400 / PANEL_WIREFRAME_W=600 / PANEL_HEIGHT=700 / HUD_WIDTH=1400` block in `openarena_perception/visualization/panels/__init__.py` with the new SSoT:
  - `PANEL_WIREFRAME_SIZE = 360`
  - `PANEL_MINIMAP_SIZE = 360`
  - `PANEL_LEFT_W = PANEL_WIREFRAME_SIZE` (360)
  - `PANEL_STATS_W = 400`
  - `PANEL_HEIGHT = PANEL_WIREFRAME_SIZE + PANEL_MINIMAP_SIZE` (720)
  - `HUD_WIDTH = PANEL_LEFT_W + PANEL_STATS_W` (760)
  - Backward-compat aliases `PANEL_MINIMAP_W = PANEL_WIREFRAME_W = 360`
- Added the three new names to `__all__`.
- `WireframePanel.__init__` default args changed from `(width=600, height=700)` to `(width=360, height=360)`. No renderer logic changes needed — `RoomConfig` already parameterises the render target, chrome scales.

### Task 2 — App recomposition + test updates

- `open_perception.py`:
  - Imports updated to pull `PANEL_WIREFRAME_SIZE, PANEL_MINIMAP_SIZE, PANEL_LEFT_W` (old `PANEL_MINIMAP_W/PANEL_WIREFRAME_W` removed from this module, aliases remain in the package).
  - `OpenPerceptionApp.__init__` now builds three subsurfaces:
    - `wireframe_surf = Rect(0, 0, 360, 360)`
    - `minimap_surf   = Rect(0, 360, 360, 360)`
    - `stats_surf     = Rect(360, 0, 400, 720)`
  - `MinimapPanel`, `WireframePanel`, `StatsPanel` instantiated at the new sizes.
  - `_draw_separators` rewritten: vertical full-height line at `x=PANEL_LEFT_W`, horizontal line at `y=PANEL_WIREFRAME_SIZE` drawn only from `x=0` to `x=PANEL_LEFT_W` (L-split).
  - Module docstring + argparse description updated to reflect `760x720`.
- `tests/test_open_perception.py::test_open_perception_app_init_window_dimensions`:
  - Now asserts `(760, 720)` window size, `(360, 360) / (360, 360) / (400, 720)` subsurface sizes, and absolute origins `(0,0) / (0,360) / (360,0)` via `get_abs_offset()`.
- `tests/test_open_perception_panels.py`:
  - `test_hud_width_is_derived` rewritten to assert the new SSoT (`HUD_WIDTH == PANEL_LEFT_W + PANEL_STATS_W == 760`, `PANEL_HEIGHT == 720`, square edges all 360, aliases equal 360).
  - Minimap/wireframe panel tests updated to use `PANEL_MINIMAP_SIZE` / `PANEL_WIREFRAME_SIZE` for both the panel constructor and the test surface so they stay square (previously they were using `PANEL_HEIGHT`, which after this plan would have created non-square 360x720 surfaces).
  - Stats panel tests left at `(PANEL_STATS_W, PANEL_HEIGHT)` — that's now `400x720`, still wide enough for the existing y-offset blocks (vital 0..120, intent 120..230, intent_history 230..330, problem_history 330..430, path_progress 430..470, verbose 470..700) with the 20px status bar margin.
