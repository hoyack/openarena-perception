# Phase 12.1: Open-Perception UI Polish - Context

**Gathered:** 2026-04-11
**Status:** Ready for planning
**Source:** Conversation with user (post Phase 12 live verification)

<domain>
## Phase Boundary

Polish pass on the Phase 12 Open-Perception HUD. Phase 12 shipped a 1400×700 three-panel layout [minimap | wireframe | stats]. Live verification against `item_tour.py --no-vision` on `oa_dm1` revealed the wireframe panel is too large and rectangular, and the minimap-beside-wireframe arrangement wastes width.

**In scope:**
- Re-shape wireframe panel into a square viewport (smaller footprint)
- Move minimap BELOW the wireframe as a square panel (relative-sized)
- Shrink overall window dimensions accordingly
- Rework minimap contents to prioritize what the bot has **learned** (learned traversable paths, visited cells, path history) over raw occupancy grid
- Add AAS overhead 2D layer on the minimap, filtered to the current floor only — show only AAS areas whose z-range contains the bot's current z coordinate
- Preserve the 9 verbose stats rows and dedup contract from Phase 12

**Out of scope (deferred to Phase 13+):**
- Room learning / room log / per-room detail memory
- Wall reconstruction from observations ("architectural lines" from bot-learned geometry)
- Active room-mapping skills
- Bot operating without AAS entirely

</domain>

- **LOCKED:** Minimap prioritizes showing what the bot has **learned** about the level's paths — learned_map traversable cells, visited positions, path history

<specifics>
## Specific Ideas

- AAS current-floor filter pseudocode:
  ```python
  def visible_areas(graph, bot_z, z_tolerance=16.0):
      return [a for a in graph.areas
              if a.mins[2] - z_tolerance <= bot_z <= a.maxs[2] + z_tolerance]
  ```
  Tolerance picks up the area the bot is standing in even with quantization noise; exact value is Claude's call.

- Learned-path rendering: draw visited learned_map cells with a dim brush, overlay the bot's recent trail (already tracked in open_perception.py) in a brighter color.

- Square wireframe viewport options:
  - Option A: Resize the underlying render surface to square (requires passing new dims through AASDepthBackend / wireframe_room)
  - Option B: Render at existing aspect ratio and letterbox/crop to a square — simpler, keeps Phase 12 internals intact
  - Planner picks.
