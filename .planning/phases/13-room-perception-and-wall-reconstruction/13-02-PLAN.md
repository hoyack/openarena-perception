Raycast record shape (locked by CONTEXT.md):
```python
class RaycastHit(NamedTuple):
    origin_x: float
    origin_y: float
    origin_z: float
    dir_angle_deg: float
    hit_x: float
    hit_y: float
    hit_z: float
    confidence: float  # from wall_score
    timestamp: float
```

Decimation policy (from RESEARCH.md and planning context):
- Cap: 5000 per floor (class constant `MAX_RAYCASTS_PER_FLOOR = 5000`)
- When `len(floor_cloud) > 5000` after append: sort by `(confidence, timestamp)` ascending, drop the worst `len - 5000` entries. This evicts oldest-lowest-confidence in one pass (numpy argsort vectorized over struct-of-arrays is fine but the list-of-NamedTuple approach is ~2-3ms for 5500 entries — acceptable since decimation runs only on overflow, not every tick)
- Evict strategy runs AT MOST once per tick; amortized O(1) since overflow is rare

Save dict schema v3 (top-level keys added):
```python
{
    ...existing v2 keys...,
    "version": 3,
    "raycasts_per_floor": [  # list-of-list-of-list, NamedTuple → list
        [[ox, oy, oz, dir_deg, hx, hy, hz, conf, ts], ...],  # floor 0
        [[ox, oy, oz, dir_deg, hx, hy, hz, conf, ts], ...],  # floor 1
    ],
    "fitted_walls": [],   # Plan 13-03 will populate
    "corners": [],        # Plan 13-04 will populate
    "rooms": [],          # Plan 13-04 will populate
    "doorways": [],       # Plan 13-04 will populate
    "wall_segments": [],  # MUST stay empty for legacy v2 loader compat
}
```

       ```python
       def _record_raycast(
           self,
           ox: float,
           oy: float,
           oz: float,
           yaw: float,
           hx: float,
           hy: float,
           hz: float,
           confidence: float,
       ) -> None:
           """Append a RaycastHit to the current floor's cloud; decimate if over cap."""
           import time
           hit = RaycastHit(
               origin_x=ox,
               origin_y=oy,
               origin_z=oz,
               dir_angle_deg=yaw,
               hit_x=hx,
               hit_y=hy,
               hit_z=hz,
               confidence=confidence,
               timestamp=time.time(),
           )
           cloud = self._raycasts_per_floor[self._current_floor]
           cloud.append(hit)
           if len(cloud) > self.MAX_RAYCASTS_PER_FLOOR:
               # Evict oldest-lowest-confidence: sort ascending by (confidence, timestamp)
               # and keep the tail. One pass, amortized O(1) since overflow rare.
               cloud.sort(key=lambda h: (h.confidence, h.timestamp))
               del cloud[: len(cloud) - self.MAX_RAYCASTS_PER_FLOOR]
               self._raycasts_per_floor[self._current_floor] = cloud
       ```
