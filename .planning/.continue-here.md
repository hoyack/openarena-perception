<decisions_made>
- Single-thought-in-flight (no queue) — simpler, thoughts supersede via staleness
- 200 unit distance staleness threshold (matches bot speed × thought latency)
- 5 second warning freshness window
- Halt only on high-severity ahead hazards (lava/ledge/drop)

- force=True release sends -action for ALL known keys, not just tracked ones

## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| Rapid jumping on stairs | +moveup every 0.1s launches bot OVER stairs into wall. Fixed in commit 192e76e. | advisory | Use spaced single jumps (1/sec) while walking |
| Holding keys across process crashes | Bot keeps walking after tour dies because pipe state persists. Fixed in commit 57b7bc7. | advisory | GameBridge.open() auto-releases |
| Steering toward AAS area centers | Area centers can be 100+ units above the floor. Use reachability start/end points instead. Fixed in commit fef6514. | advisory | Check navigator.follow_path() uses reach.start/end |
| Rapid weapon cycling from moveup | cg_autoswitch and mwheelup/down binds cause weapon cycling during jumps. Fixed in autoexec.cfg. | advisory | Keep autoexec.cfg settings intact |
